# Gator's Dockside Benefits Enrollment (Demo)

An online open enrollment form built by Key HR. Employees choose their benefits, sign, and get a PDF copy. Each enrollment is saved to a private Google Sheet and Drive folder, and Key HR reviews submissions from a password-protected admin page. Key HR staff can also sign in and complete an enrollment on an employee's behalf.
